## 🎯 Objetivo do Projeto

Criar um site moderno e funcional para apresentar a instituição, facilitando o acesso às informações principais da escola de forma clara, bonita e intuitiva.

O projeto busca:
- Melhorar a presença digital da instituição
- Centralizar informações importantes
- Oferecer uma navegação simples e fluida
- Servir como base para futuras evoluções
